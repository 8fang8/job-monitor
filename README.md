# 贵阳求职岗位自动监控系统
双非文科硕士专属 · 云端自动运行 · 无需本地装Python

## 功能清单
✅ 每日自动抓取贵阳高校/事业单位/国企新岗位，自动去重不重复
✅ 完整岗位信息：名称、单位、投递链接、发布日期、截止时间
✅ 投递进度台账：6种状态手动标记，数据永久保存
✅ 网申截止预警：7天内截止自动高亮，避免错过
✅ 内置问答库：档案、贵阳补贴、文科就业一键查询

## 部署方式
1. 本仓库托管在 GitHub，数据永久保存
2. 对接 WorkBuddy 云端执行，Windows电脑关机也能每日更新
3. 所有操作通过 WorkBuddy 客户端自然语言指令完成

## 日常指令（发给WorkBuddy即可）
- 今天有什么新岗位？
- 查看7天内截止的岗位
- 把XX岗位标记为已投递
- 查看我的投递台账
- 贵阳硕士补贴怎么申请？
